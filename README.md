# Projeto Tecnológico · Sala Inteligente

Site estático criado a partir do ficheiro Word do projeto de registo de entradas e saídas da sala de aula.

## Conteúdo
- Página principal em HTML/CSS/JS
- Visualização do documento Word no navegador
- Download do ficheiro original
- Design responsivo para desktop e mobile

## Como executar
1. Abra o terminal na pasta do projeto.
2. Execute:
   ```bash
   python -m http.server 8000
   ```
3. Aceda a:
   ```text
   http://localhost:8000
   ```

## Ficheiros importantes
- `index.html` — página principal do site
- `styles.css` — estilos do design
- `script.js` — carregamento e conversão do ficheiro Word
- `Planificacao_Projeto_Registo_Entradas_Saidas.docx.docx` — documento original em Word
